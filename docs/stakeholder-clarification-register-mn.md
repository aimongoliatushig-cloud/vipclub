# Оролцогч талуудын тодруулгын бүртгэл

Энэ бүртгэл нь CEO, ерөнхий менежер, салбарын менежер, ХН, нягтлан бодох, маркетинг болон техникийн эзнээс авах шийдвэр, дутуу өгөгдөл, баталгаажуулалтыг хөтөлнө. **Нээлттэй** асуудлыг далд таамаглал болгон хэрэгжүүлэхгүй.

## Ашиглах заавар

- **Статус:** Нээлттэй, Санал болгосон, Батлагдсан, Хойшлуулсан, Хүчингүй болсон.
- **Шийдвэрийн эзэн:** Хариулт, баталгааг хариуцах хүн эсвэл баг.
- **Эрсдэл:** Өндөр эрсдэл нь санхүү, хууль, зөвшөөрөл, үндсэн өгөгдөлд нөлөөлнө.
- Шийдвэр батлагдмагц холбогдох шаардлага, процесс, өгөгдлийн загвар, Linear ажлын холбоосыг оруулна.
