# Development Guide

## Local setup

Document prerequisites, environment variables, installation, and how to run the application.

## Delivery workflow

1. Create or link a requirement.
2. Implement with tests and documentation updates.
3. Request review.
4. Validate in the target environment.
5. Record release notes and operational changes.

## Quality standards

- Add appropriate automated tests.
- Keep secrets out of the repository.
- Update the knowledge base when a product, process, architecture, or model decision changes.
